# Dotnote 0.2.6 — AI image mode in the note

## Updates

- **Note writing keeps reasoning off** — Ask AI uses models with thinking disabled where the provider allows it; always-reasoning models are hidden from the picker
- **Generate image is a mode, not a shortcut** — Choose **Generate image**, describe what you want, pick an image model in the bar, then send. Nothing runs until you enter a prompt
- **Progress in the note** — A placeholder appears in the document with an estimated percentage and **Stop** while the image generates; the finished image replaces it in place
- **Edit with AI on existing images** — Select an image and press **⌘J** (or **Ask AI**) to use it as input; the new image is inserted below the original
- **Installer** — The deploy wizard ends on a **Finished** step with your Dotnote address and a short hint if the site is still starting
