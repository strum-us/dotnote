# Dotnote 0.1.0 — Your notes, on your Cloudflare

## Workspace

- **Block editor** with folder trees, drag-reordered tabs, and preview vs. pinned notes
- Note titles come from the first `# Heading` — rename the heading, rename everywhere
- **Import** a folder of markdown files and keep writing

## Speed & sync

- Notes paint instantly from local storage and sync in the background
- **Offline editing** queues every change and retries automatically
- `⌘K` full-text search across every note, indexed in a Web Worker
- **History** keeps up to 100 snapshots per note — preview the diff, restore any version

## AI

- Press `⌘J` or select text and choose **Ask AI** — improve, summarize, translate, continue
- **Bring your own key**: Anthropic, OpenAI, xAI, or Google Gemini, billed by the provider
- Keys live on your Worker; the browser only sees a masked copy

## Sharing & install

- **Share links** per note — create and revoke from the note itself
- Guided install deploys the Worker, D1 database, and R2 bucket into your Cloudflare account
