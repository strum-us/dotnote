# Dotnote 0.2.0 — Keeps itself up to date

## Self-update

- **Dotnote updates itself.** When a new version is out, the sidebar offers it: database changes are applied, the Worker in your Cloudflare account is replaced, and the page reloads
- Your notes in R2 and D1 stay where they are; the update only swaps Dotnote's code and adds new tables
- **Settings › Cloudflare** shows the running version, checks for updates on demand, and can go back to the version you updated from
- Uses the Cloudflare permission stored at install — if it cannot replace the Worker, the sidebar offers **Reconnect**
- Dotnotes installed from this version on update themselves

## AI images

- **Generate images** from the AI bar with Google Gemini — preview the result, then insert it into the note
- Images save to your R2 bucket like pasted uploads
- Pick the model and aspect ratio in **Settings › AI Image**; it uses its own Gemini key, separate from the text model

## AI models

- Model pickers show **input and output pricing** for each model
- The active provider list only offers providers you have added a key for
