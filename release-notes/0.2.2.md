# Dotnote 0.2.2 — Updates page and installer repair

## Updates

- **Settings › Updates** — check for releases, see installed vs latest version, update, roll back, and read release notes in one place
- Clearer messages when self-update is blocked (missing Cloudflare permission, rollout hold, and similar)

## Installer

- **Update or repair** an existing Dotnote instead of stopping when a Worker is already on your account
- Review step reflects existing resources so reinstall and repair flows are easier to follow

## Optional registration

- **Settings › Account** — opt in to register this deployment with Dotnote Cloud for operator notices (no note titles, bodies, or passwords)
- **View exact payload** before you consent; turn registration off anytime in Settings
