# Dotnote 0.2.4 — Updates without signing in again

## Updates

- **Automatic updates**: turn on **Settings › Updates › Install new releases on their own** and Dotnote checks every 30 minutes and installs new releases, even with no tab open. Off until you turn it on
- An update that a closed tab left halfway now finishes on its own
- **Signed releases**: Dotnote checks the release signature and every file before it installs anything, and refuses a release that does not match

## Cloudflare

- **Unfinished installs**: if the install page closed before Dotnote received its Cloudflare permission, open the installer and choose **Continue here** to finish from any browser
