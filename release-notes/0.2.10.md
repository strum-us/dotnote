# Dotnote 0.2.10 — AI usage log and settings routes

## Settings

- **AI, AI Image, and Log tabs** — One **AI** item in the sidebar with nested routes (`/settings/ai`, `/settings/ai/image`, `/settings/ai/logs`). Tab changes update the URL immediately via React Router
- **Usage log** — Recent text and image requests with token estimates, catalog-based costs, 7-day / 30-day / all-time filters, load-more paging, and a detail sheet for input and output

## Backend

- **`ai_logs` table** — Worker records each LLM generate and image request for the signed-in user
