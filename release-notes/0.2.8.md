# Dotnote 0.2.8 — OpenAI image generation works again

## AI images

- **GPT Image 2.5 Flare and Sunburst** — Current OpenAI image models in the picker; DALL·E 3 and DALL·E 2 selections map to these automatically
- **Fixed OpenAI image API calls** — Removed the deprecated `response_format` parameter so generation and edits succeed with project keys (`sk-proj-…`)
- **Clearer errors** — OpenAI failures show the provider message (quota, model access, invalid key) instead of a generic “rejected the API key”
- **Safer API key storage** — Trim invisible characters and fix AES key parsing so saved OpenAI keys are not corrupted
