# Dotnote 0.2.1 — Smoother first load

## Fixes

- **No more empty flash on open.** While workspaces and docs load from cache or the server, the sidebar and editor show loading placeholders instead of “Select a note or create one” with an empty Docs list
- **Sample entry** primes your session before redirect so the playground opens with less flicker
- **Offline manifest failure** shows a retry action instead of looking like an empty workspace
