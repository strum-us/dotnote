# Dotnote 0.2.5 — One way to connect Cloudflare

## Updates

- Dotnote updates itself only with the Cloudflare permission it received from the installer. **Settings › Cloudflare** no longer asks for an API token
- **Deployed with wrangler?** Run the installer once for the same Worker (repair keeps your notes). Dotnote then updates itself like any guided install
- When an update cannot reach Cloudflare, the message now says what to do
